# screen commands

### Connecting to switches

```bash
sudo screen /dev/ttyUSB0 9600

```

### For Cisco Nexus / CBS lines or modified switches
```bash
sudo screen /dev/ttyUSB0 115200
```

### Other common alternative debugging speeds
```bash
sudo screen /dev/ttyUSB0 57600
```

```bash
sudo screen /dev/ttyUSB0 19200
```
